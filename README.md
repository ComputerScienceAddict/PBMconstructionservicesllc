# PBM Construction Services LLC – Website

A React + Next.js website for PBM Construction Services, built around their branding, equipment photos, and business card details.

## Design

- **Colors:** Red (#b91c1c / red-700) as primary, stone/gray tones, dark charcoal for contrast
- **Fonts:** Oswald for headings, DM Sans for body
- **Layout:** Sections for Hero, Services, Gallery, About, Contact, Footer
- **Images:** Project photos and branding assets in `/public/images`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```
